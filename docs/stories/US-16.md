# US-16 — Langues et liens

Phase 4 · MUST · 2 points · dépend de US-13 · réf. F-CAND-02

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| Langue avec niveau A1 à C2 ou NATIVE, sans doublon | `CandidateProfileIT.languagesAreUniqueAndLevelled` ; `CandidateProfileTest.sameLanguageTwiceIsRejected` ; validateur `uniqueBy` (`forms.spec`) |
| Lien non https ou 6e lien → refus | `linksMustBeHttpsAndAtMostFive` ; `ValidatorsTest` (`@HttpsUrl`) ; `CandidateProfileTest.sixLinksAreRejected` ; bouton d'ajout désactivé à 5 |

## 2. Fichiers

`candidate/domain/CandidateLanguage`, `CandidateLink`, `LanguageLevel`, `LinkType`, `ProfileRules` ; `shared/validation/HttpsUrl` ; frontend `components/languages-editor.ts`, `links-editor.ts`, `shared/forms/validators.ts` (`httpsUrl`, `uniqueBy`).

## 3. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| Collections d'éléments (`@ElementCollection`, listes) | Entités avec identifiant | Valeurs sans identité, toujours remplacées en bloc ; avec une liste, Hibernate supprime puis réinsère les lignes, ce qui évite les comparaisons sur des colonnes nulles |
| `id` de `candidate_link` rempli par `uuidv7()` en base | Identifiant géré par Hibernate | Le modèle de données garde une clé primaire, sans en faire une identité côté Java |
| `@HttpsUrl` analyse l'URL (schéma exact, hôte avec un point) | Expression régulière | Refuse `javascript:`, `data:`, `HTTPS://` (incompatible avec la contrainte SQL) et les hôtes locaux |
| Liste fermée de langues dans l'interface | Saisie libre | Choix rapide et codes ISO 639 garantis |

## 4. Questions d'entretien

**« Pourquoi refuser `http://` ? »** Le lien est affiché aux recruteurs : https évite qu'un lien soit intercepté ou modifié en route, et l'analyse de l'URL ferme la porte aux schémas exécutables.
