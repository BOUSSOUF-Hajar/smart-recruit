# US-46 — Tableau de bord admin

Phase 10 · SHOULD · 3 points · dépend de US-48 · réf. D8

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| Utilisateurs par rôle (actifs et désactivés), entreprises, offres par statut, total des candidatures, état de l'IA | `AdminDashboardIT.countsUsersByRoleAndStateCompaniesJobsApplicationsAndShowsTheAiState` (écarts mesurés avant et après la création puis la désactivation d'un recruteur ; IA disponible avec le nom du modèle) ; `admin-dashboard.page.spec` |
| Ollama arrêté → « indisponible » | `AiStatusAdapterTest.stoppedOllamaIsShownUnavailableWithTheConfiguredModel` (indicateur de santé pointé vers un port fermé) ; bandeau rouge à l'écran, qui précise que le reste de la plateforme fonctionne |

Compléments : IA désactivée → « Désactivée » sans sonde ; le résultat de la sonde est gardé 30 s (`theProbeResultIsKeptThirtySeconds`) ; tous les rôles et statuts sont présents, à zéro s'il le faut.

## 2. Fichiers

- Backend : `ai/api/AiStatus` (nouvelle API publique du module IA), `ai/infrastructure/AiStatusAdapter` ; `reporting/infrastructure/DashboardQueries` (requêtes admin), `DashboardService.admin`, `DashboardController` (`GET /admin/dashboard`).
- Frontend : `pages/admin-dashboard.page.ts` ; `shared/ui/stat-tile` (le lien devient facultatif).

## 3. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| État de l'IA lu sur l'indicateur de santé d'Ollama, mis en cache 30 s | Appel à Ollama à chaque affichage | Un serveur injoignable coûterait le délai de connexion à chaque chargement |
| Comptes et entreprises cliquables vers leurs listes filtrées ; offres et candidatures non cliquables | Tout cliquable | L'admin n'a aucune liste de candidatures (il ne voit aucun dossier) |
| Agrégats SQL dans le module `reporting` | Un appel par module | Même exception documentée que les tableaux de bord recruteur et candidat (US-44) |
