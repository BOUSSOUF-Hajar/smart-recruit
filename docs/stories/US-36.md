# US-36 — Reprogrammer ou annuler

Phase 7 · SHOULD · 3 points · dépend de US-35 · réf. F-INT-02, F-INT-03

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| SCHEDULED reprogrammé → ancienne et nouvelle date dans l'historique | `InterviewIT.rescheduleKeepsBothDatesAndFinishedInterviewsAreReadOnly` (`previousStartsAt`, `startsAt`) ; `InterviewTest.rescheduleReturnsThePreviousDate` |
| Annulation → CANCELLED, motif facultatif | Même test ; dialogue d'annulation |
| COMPLETED ou CANCELLED → modification refusée | Même test (409 `INVALID_STATE`) ; `finishedInterviewsCannotChange` ; la carte n'affiche plus aucune action (`InterviewCard` spec) |
| (ajout) Modification concurrente → `CONCURRENT_MODIFICATION` | Même test (version périmée) |

## 2. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| `PUT` complet avec `version` | `PATCH` de la date seule | Un même formulaire modifie date, lieu et participants ; le verrou optimiste protège deux recruteurs |
| État vérifié avant les champs (`checkModifiable`) | Validation d'abord | Un entretien annulé répond « annulé », pas « date dans le passé » |
| Motif d'annulation interne | Visible du candidat | Il peut contenir des informations internes ; le candidat voit seulement « Annulé » |
