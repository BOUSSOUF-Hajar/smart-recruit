# US-11 — Changer mon mot de passe

Phase 3 · SHOULD · 3 points · dépend de US-07 · réf. F-AUTH-05, F-AUTH-06

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| Ancien mot de passe correct + nouveau valide → changement, autres sessions révoquées | `AuthFlowIT.changingThePasswordClosesOtherSessions`, `wrongCurrentPasswordIsRejected` |
| Compte « à changer » → `PASSWORD_CHANGE_REQUIRED` partout sauf le changement, écran de changement affiché | `temporaryPasswordMustBeChangedBeforeAnythingElse` ; `guards.spec` (`passwordChangeGuard`) ; `LoginPage` spec |

## 2. Fichiers

| Fichier | Rôle |
| --- | --- |
| `identity/application/AccountService.java` | Vérification, nouveau hash, révocation des autres sessions, audit |
| `shared/security/PasswordChangeRequiredFilter.java` | 403 tant que le claim `pwdChange` est présent, sauf `/me`, `/auth/password`, `/auth/logout` |
| `identity/web/ChangePasswordRequest.java`, `MeController.java` | Corps validé ; `/me` toujours accessible |
| Frontend `features/account/pages/change-password.page.ts`, `shared/forms/validators.ts` | Formulaire avec confirmation (validateur de groupe) |
| Frontend `core/http/error.interceptor.ts` | `PASSWORD_CHANGE_REQUIRED` → navigation vers `/account/password` |

## 3. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| Marqueur `pwdChange` dans le token | Lecture de `must_change_password` à chaque requête | Aucune requête en base ; le marqueur disparaît au renouvellement qui suit le changement |
| Session courante conservée (reconnue par son cookie) | Tout révoquer et forcer une reconnexion | L'utilisateur qui vient de prouver son identité n'a pas à se reconnecter ; l'intrus, lui, perd l'accès |
| Filtre après `BearerTokenAuthenticationFilter` | Règle dans `authorizeHttpRequests` | Il faut le token déjà décodé, et la règle s'applique à tous les endpoints |
| Filtre non déclaré `@Component` | `@Component` | Spring Boot l'enregistrerait aussi comme filtre servlet, hors de la chaîne de sécurité |

## 4. Questions d'entretien

**« Pourquoi révoquer les autres sessions ? »** On change souvent de mot de passe parce qu'on le croit compromis : les sessions ouvertes par un intrus doivent tomber en même temps.
