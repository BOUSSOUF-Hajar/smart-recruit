# US-50 — Gérer les catégories

Phase 10 · MUST · 2 points · dépend de US-47 · réf. F-ADM-04, RG-30

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| Nouvelle catégorie au nom unique → proposée dans le formulaire d'offre | `AdminReferentialIT.aNewCategoryIsOfferedInTheJobFormAndNamesStayUnique` (présente dans `GET /categories`, doublon sans tenir compte de la casse → `RESOURCE_IN_USE`, création et renommage audités) |
| Catégorie utilisée → `RESOURCE_IN_USE` à la suppression, désactivation proposée | `aUsedCategoryCannotBeDeletedOnlyDeactivated` (409 avec `usageCount`, puis désactivation : absente de la liste publique, refusée pour une nouvelle offre, toujours visible par l'admin) ; `category-list.page.spec` (l'écran enchaîne sur la proposition de désactivation) |

Complément : une catégorie inutilisée se supprime (`anUnusedCategoryIsDeletedAndAudited`).

## 2. Fichiers

- Backend : `referential/application/AdminCategoryService`, `web/AdminCategoryController`, `infrastructure/ReferentialConstraints` ; `referential/api/ReferentialUsage`, implémentée par `job/infrastructure/JobReferentialUsage` ; index `ix_job_offer_category` (V14).
- Frontend : `categories/category-list.page.ts`, `components/name-dialog.ts`.

## 3. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| Comptage des offres via `ReferentialUsage`, interface du module Référentiels implémentée par les modules qui y font référence | Requête SQL de `referential` sur `job_offer` | Le référentiel est en bas de la chaîne : Offres et Candidats dépendent de lui, pas l'inverse |
| Vérification applicative **et** clé étrangère traduite (`fk_job_offer_category` → `RESOURCE_IN_USE`) | Seulement l'une des deux | La vérification donne un message clair avec le nombre d'offres ; la contrainte arrête une offre créée au même instant |
| Désactivation plutôt que suppression d'une catégorie utilisée | Suppression en cascade ou réaffectation | RG-30 : les offres existantes gardent leur catégorie et restent cohérentes |
