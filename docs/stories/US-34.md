# US-34 — Historique de candidature

Phase 6 · MUST · 3 points · dépend de US-32 · réf. F-HIST-01, RG-24

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| Entrée horodatée avec auteur à chaque événement, dans la même transaction | `RecruiterApplicationIT.applicationMovesForwardUntilAnInterviewAndEachStepIsInTheHistory` (auteurs « Youssef Alami » et « Salma Idrissi ») ; `ApplicationHistoryListener` synchrone. Création et statuts en phase 6 ; notes, entretiens et IA ajouteront leurs types (déjà présents dans la contrainte CHECK) |
| Plus récent d'abord ; aucune modification ni suppression | Même test (ordre) ; `historyCannotBeModifiedNorDeleted` : UPDATE et DELETE refusés par le déclencheur `trg_application_event_immutable` |
| Le candidat ne voit que les statuts, simplifiés | `CandidateTimelineTest` ; `candidateSeesSimplifiedStatusesAndNothingInternal` |

## 2. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| Écriture par écouteur d'événements synchrone | Écriture directe dans le service ; écouteur asynchrone | Le service ne connaît pas l'historique ; synchrone = même transaction, aucune entrée perdue |
| JDBC (`HistoryRepository`) et record `HistoryEntry` | Entité JPA | Aucune méthode de mise à jour possible ; le JSONB passe par Jackson 3 sans adaptateur Hibernate |
| Déclencheur qui refuse UPDATE et DELETE | Discipline applicative seule | Protège aussi d'un script ou d'une console |
| Noms des auteurs en une requête (`UserAccounts.findAll`) | Une requête par entrée | Pas de N+1 ; méthode ajoutée à l'API du module Identité |
| Tri `occurred_at DESC, id DESC` | Date seule | Deux événements à la même milliseconde restent ordonnés (UUIDv7 croissant) |

## 3. Question d'entretien

**« Historique de candidature ou journal d'audit ? »** L'historique raconte la vie métier d'une candidature, lisible par le recruteur. L'audit trace les actions sensibles de tous les utilisateurs pour l'admin (connexions, téléchargements). Les deux sont immuables, pour des publics différents.
