# US-38 — Mes entretiens (candidat)

Phase 7 · SHOULD · 2 points · dépend de US-35 · réf. F-INT-05, RG-23, RG-32

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| Date, heure dans mon fuseau, type, lieu ou lien, instructions ; prochains en premier | `InterviewIT.candidateSeesUpcomingInterviewsWithoutFeedbackNorParticipants` (ordre, lien, instructions) ; page `MyInterviewsPage` (sections « À venir » et « Passés », dates affichées par le navigateur) |
| Entretien annulé → affiché comme annulé | Même test (`CANCELLED` dans la liste à venir), sans le motif interne |
| (ajout) Résumé des entretiens dans le détail de la candidature | `interviews` du détail candidat (3 entretiens, sans lieu ni avis) |

## 2. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| `GET /candidates/me/interviews?upcoming=` dans le module Entretiens | Endpoint dans le module Candidatures | L'entretien appartient à son module ; il obtient les candidatures du candidat par `ApplicationDirectory.idsOfCandidate` |
| Vue candidat sans type commun avec la vue recruteur | Une vue avec champs masqués | L'avis et les participants ne peuvent pas fuiter par sérialisation |
| Lien et adresse affichés seulement pour un entretien planifié | Toujours | Un lien d'entretien annulé n'a plus de sens |
