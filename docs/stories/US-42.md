# US-42 — Score de matching

Phase 8 · MUST · 8 points · dépend de US-41 · réf. F-AI-03, analyse fonctionnelle §5

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| Exemple chiffré §5.5 → 81, « Forte adéquation » | `MatchingCalculatorTest.theWorkedExampleScores81StrongFit` (écrit en premier : C_req 0,9, C_souh 0,333, A 1) |
| Sans compétence souhaitée → poids 75 / 25 | `withoutPreferredSkillsTheWeightsAre75And25` |
| CV pas encore analysé → analyse lancée d'abord | `AiIT.matchingAnalysesFirstScoresFromTheBackendAndChangesNoStatus` (analyse enregistrée par la tâche de matching ; un second matching la réutilise) |
| Décomposition, compétences correspondantes, manquantes requises et souhaitées séparées, points forts et faibles, synthèse, mention « aide à la décision » | Même test (réponse de l'API) ; `AiPanel` spec |
| Le modèle répond avec un autre score → ignoré | `OllamaAIServiceTest.aScoreReturnedByTheModelIsIgnored` (champ hors schéma ignoré) ; aucun champ « score » dans `MatchExplanation` ; le score enregistré vient de `MatchingCalculator` |
| (ajout) Cas limites §5.3 | `unknownExperienceCountsForZeroUnlessNoneIsRequired` (A = 0 et avertissement), `profileLevelWinsAndNothingIsInferred`, CV scanné → calcul sur le profil avec avertissement (`AiIT`) ; `ExperienceYearsTest` (chevauchements comptés une fois) |

## 2. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| `MatchingCalculator` pur, sans Spring | Score demandé au modèle | Reproductible, testable, explicable ; insensible aux consignes cachées dans un CV |
| Comparaison par identifiant du référentiel, sans déduction (Spring Boot ≠ Java) | Similarité de texte | Plus strict, jamais faux (§5.1) |
| Profil prioritaire sur le CV ; niveau inconnu (CV) compté 1 | CV prioritaire | Le niveau déclaré est la seule information de niveau disponible |
| `formula_version` enregistrée | Formule implicite | Un ancien score reste explicable après une évolution de la formule |
| Le modèle reçoit la décomposition (compétences, couvertures), jamais l'identité | CV complet | Il explique un chiffre qu'il ne peut pas changer, avec le moins de données possible |
| Copie du score sur la candidature par une mise à jour ciblée (sans version) | Modification de l'entité | Un résultat qui arrive pendant la lecture du dossier ne provoque pas de conflit de version au changement de statut |

## 3. Questions d'entretien

**« Pourquoi 81 et pas 80,7 ? »** `round(100 × 0,807)`. Le libellé suit des seuils de lecture (75 / 50) qui ne servent jamais à trier ni à filtrer (RG-25).

**« Que fait le LLM, alors ? »** Deux choses : extraire des données structurées du CV, et rédiger l'explication d'un score déjà calculé.
