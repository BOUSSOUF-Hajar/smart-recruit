# US-19 — Supprimer mon CV

Phase 6 · SHOULD · 2 points · dépend de US-17, US-27 · réf. F-CAND-04, RG-12

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| CV jamais envoyé → fichier et métadonnées effacés | `CandidateApplicationIT.neverSentResumeIsErased` ; `ResumeServiceTest.deletedResumeFileIsRemovedAfterTheDatabase` |
| CV joint à une candidature → seulement désactivé, visible des recruteurs concernés | `resumeSentWithAnApplicationIsOnlyDeactivatedAndStaysAvailableToTheRecruiter` ; `attachedResumeIsOnlyDeactivatedAndItsFileKept` |
| Aucun CV actif → on indique d'en téléverser un pour postuler | `neverSentResumeIsErased` (`PROFILE_INCOMPLETE`, `missing: [resume]`) ; dialogue « Postuler » avec lien vers l'onglet CV |

## 2. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| `ResumeUsage` déclaré par Candidats, implémenté par Candidatures | Candidats interroge la table `application` | Le sens des dépendances reste Candidatures → Candidats |
| Base d'abord (transaction courte), fichier ensuite | Fichier d'abord | En cas d'échec, il reste au pire un fichier orphelin, jamais une ligne qui pointe vers un fichier absent |
| Confirmation qui dit que les recruteurs gardent le CV déjà envoyé | Confirmation générique | Le candidat ne doit pas croire l'avoir retiré de partout |
| Course avec une candidature simultanée → `fk_application_resume` → `CONCURRENT_MODIFICATION` | Verrou sur le CV | Cas rare ; la base garantit la cohérence, l'utilisateur réessaie |
