# US-29 — Retirer ma candidature

Phase 6 · MUST · 3 points · dépend de US-28, US-32 · réf. F-APP-03, RG-15, RG-22

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| Candidature non finale → WITHDRAWN ; entretiens planifiés annulés | `CandidateApplicationIT.withdrawalIsFinalAndForbidsApplyingAgain` ; `ApplicationWorkflowTest`. **Annulation des entretiens** : l'événement `ApplicationStatusChanged` (avec `endsTheProcess()`) est publié dans la transaction ; le module Entretiens l'écoutera en phase 7, quand les entretiens existeront — **fait en phase 7** : `ApplicationOutcomeListener` (module Entretiens), testé par `InterviewIT.rejectingTheApplicationCancelsItsScheduledInterviews` et `withdrawalCancelsScheduledInterviewsToo` |
| HIRED, REJECTED ou déjà WITHDRAWN → `INVALID_STATUS_TRANSITION` | Même test (second retrait) ; matrice des 64 couples |
| Retirée → impossible de postuler à nouveau | Même test : `APPLICATION_ALREADY_EXISTS` (RG-10, quel que soit le statut) ; le détail de l'offre affiche « Suivre ma candidature » (`myApplicationId`) |
| (ajout) Commentaire facultatif lu par le recruteur | Même test : il apparaît dans l'historique recruteur |

## 2. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| `POST /candidates/me/applications/{id}/withdraw` | `PATCH /status` partagé | Le candidat n'a qu'une transition ; une action dédiée évite d'exposer le vocabulaire interne |
| Confirmation qui annonce l'irréversibilité et RG-10 | Confirmation générique | Le candidat doit savoir qu'il ne pourra plus repostuler |
| Pas de contrôle de version côté candidat | Version obligatoire | Une seule personne agit sur sa candidature ; un recruteur qui rejette en même temps fait échouer la transition suivante (409), affiché proprement |

## 3. Question d'entretien

**« Le retrait annule les entretiens : comment, sans que Candidatures dépende d'Entretiens ? »** Candidatures publie `ApplicationStatusChanged` ; Entretiens l'écoutera de façon synchrone (même transaction). La dépendance va d'Entretiens vers Candidatures, jamais l'inverse.
