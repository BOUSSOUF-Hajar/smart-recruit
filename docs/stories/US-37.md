# US-37 — Clôturer un entretien

Phase 7 · MUST · 2 points · dépend de US-35 · réf. F-INT-04, RG-23, RG-33

## 1. Objectif et critères

| Critère d'acceptation | Preuve |
| --- | --- |
| Heure de début passée → COMPLETED avec avis et commentaire | `InterviewIT.completedInterviewUnlocksTheOfferAndTheHiring` ; `InterviewTest.completionNeedsAParticipantAndAStartedInterview` |
| Pas encore commencé → refus | Même test (409 `INVALID_STATE`) ; le bouton « Clôturer » n'apparaît qu'après le début (`hasStarted`, `InterviewCard` spec) |
| Feedback jamais visible du candidat | `candidateSeesUpcomingInterviewsWithoutFeedbackNorParticipants` (réponses brutes sans `feedback`, avis, commentaire ni participants) |
| (ajout) Seul un participant clôture | 403 `ACCESS_DENIED` pour un collègue non participant (F-INT-04) |
| (ajout) RG-33 de bout en bout : SUBMITTED → HIRED | Même premier test : OFFER refusé avant la clôture, proposé et accepté après, puis HIRED ; le candidat voit « Retenue » |

## 2. Choix techniques

| Choix | Alternative écartée | Raison |
| --- | --- | --- |
| `InterviewOverviewAdapter` implémente `CompletedInterviewChecker` (déclaré par Candidatures en phase 6) | Candidatures interroge la table `interview` | Le point d'extension prévu en phase 6 se remplit sans modifier le module Candidatures |
| 403 pour un non-participant | 404 | L'entretien est visible de toute l'entreprise ; seule l'action est réservée |
| Contrainte `ck_interview_completion` : avis et date présents si et seulement si COMPLETED | Contrôle applicatif seul | Pas d'entretien terminé sans avis, même par un script |

## 3. Question d'entretien

**« Comment testez-vous "après l'heure de début" sans attendre ? »** En avançant la date de l'entretien directement en base dans le test d'intégration ; les règles temporelles elles-mêmes sont testées en unitaire avec un instant fixé.
